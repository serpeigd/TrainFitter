# Generación/lectura de PDF — agents/pdf_generador.py: el PDF de dieta y el
# checklist rellenable adjuntos al email (ver mcp/gmail_client.py); también
# agents/pdf_intake.py: la ficha de admisión rellenable que un cliente nuevo
# puede devolver por email (ver main.py y el uploader de ui/app.py). reportlab

# vuelta los valores que rellenó el cliente. Ambos gratis, sin API, sin
# dependencias de sistema:

pypdf>=5.0.0

# Gráficos de tendencia (ui/app.py: peso/adherencia a lo largo del tiempo,
# tanto en el panel del entrenador como en el portal del cliente).
# st.line_chart() necesita Altair para dibujar -- streamlit lo declara como
# dependencia propia, pero un entorno real de este proyecto ha llegado a
# tenerlo instalado sin él de todos modos y el gráfico lanzó
# ModuleNotFoundError en vivo (visto, no solo asumido). pandas arma los
# DataFrame que le pasamos a st.line_chart() (la lista "todos los
# clientes" de más abajo NO necesita pandas -- st.dataframe() acepta una
# lista de diccionarios directamente). El código además degrada solo (sin
# gráfico, resto de la página intacta) si por lo que sea alguno de los
# dos no está instalado, pero para que el gráfico funcione de verdad hace
# falta esto:
altair>=5.0.0
pandas>=1.4.0
